# zentry-ecommerce

Este proyecto consiste en un backend desarrollado con **Spring Boot** y una base de datos en **MySQL**.


## 📦 Requisitos

- Java 17
- Maven
- MySQL Server
- IDE recomendada: IntelliJ IDEA, Eclipse o VS Code con soporte para Spring Boot
